# تحليل المشاكل والإصلاح

## المشكلة #1 — فرق وهمي 2,000 ر.س عند التسوية رغم أن الدفعة منتهية

**التحليل العميق:**
في `src/components/project/FundsSection.tsx`:

- **سطر 399** (صف الدفعة في الجدول) يحسب المصروف بـ:
  ```ts
  getFundSpent(f.id, projectExpenses, projectCustodies, projPRs, projTransfers)
  ```
  → يشمل: مصروف مباشر + عهد + **سلف قائمة** + **تحويلات نقدية**.
  النتيجة في الصورة: **67,000 ر.س مصروف، 0 متبقي** ✅

- **سطر 163-165** (نافذة التسوية) يحسب المصروف الموثق بـ:
  ```ts
  getFundSpent(settleFor.id, projectExpenses, projectCustodies)  // ناقص!
  ```
  → يشمل فقط: مصروف مباشر + عهد. **يُسقط السلف والتحويلات النقدية**.
  النتيجة في الصورة: **65,000 ر.س مصروف موثق، فرق 2,000 ر.س** ❌

السلفة المعلّقة (2,000 ر.س) والتحويلات النقدية إلى العهد جزء من خروج الدفعة فعلياً، ويجب احتسابها ضمن "المصروف الموثق" في التسوية حتى لا يظهر فرق وهمي.

**الإصلاح:**
- تمرير `projPRs` و`projTransfers` إلى `getFundSpent` في حساب `settlementSpent`.
- إضافة تفصيل صغير تحت الكارت يوضح المكونات (مباشر / عهد / سلف قائمة / تحويلات نقدية) لتفسير الرقم للمستخدم.

## المشكلة #2 — أيقونة "ربط بدفعة" تظهر على مصروف مربوط بعهدة

**التحليل:**
في `src/components/project/ExpensesSection.tsx` سطر 719:
```tsx
{!exp.fundId && activeFund && (<Button ...>Wallet icon</Button>)}
```
الشرط يتجاهل `exp.custodyId`. المصروف المرتبط بعهدة لا يحتاج (ولا يجوز) ربطه مباشرة بدفعة — لأن العهدة نفسها مسحوبة من دفعة، والربط المزدوج يسبب احتساب مضاعف ولبس بصري.

**الإصلاح:**
تعديل الشرط ليصبح:
```tsx
{!exp.fundId && !exp.custodyId && activeFund && (...)}
```
بحيث تظهر الأيقونة فقط للمصروفات المباشرة غير المرتبطة بأي مصدر تمويل.

## الملفات المعدّلة
1. `src/components/project/FundsSection.tsx` — تصحيح `settlementSpent` + إضافة تفصيل المكونات في الـ Dialog.
2. `src/components/project/ExpensesSection.tsx` — إخفاء أيقونة الربط عند وجود `custodyId`.

## التحقق
- تشغيل `vitest run` (81/81 يجب أن تبقى خضراء).
- إضافة اختبار يتأكد أن `settlementSpent` للدفعة #1 (الموصوفة في الصورة) = 67,000 ر.س → الفرق = 0.
- مراجعة بصرية: نافذة التسوية يجب أن تُظهر **المصروف الموثق 67,000 / الفرق 0**، وأيقونة Wallet لا تظهر بجانب أي مصروف له `custodyId`.
