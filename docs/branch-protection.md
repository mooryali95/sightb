# حماية فرع `main` — الإعداد الموصى به

> **الحالة:** غير مُفعَّلة · **الأثر:** أعلى عائد لكل دقيقة في التقرير كله
> **التنفيذ:** يحتاج صلاحية مالك المستودع — لا يمكن تطبيقه من جلسة العمل.

---

## لماذا هذا أول ما يجب فعله

ليس بنداً من بنود التقرير، بل شرط لصلاحية بقيتها. الدليل من هذا المستودع نفسه:

- CI على `main` ظلّ **أحمر ثمانية أيام متتالية** (3–11 أغسطس، ثماني تشغيلات فاشلة) دون أن يلاحظه أحد، فحُجب كل طلب دمج في تلك الفترة.
- السبب كان نتيجة إيجابية كاذبة في حارس طبقة البيانات — لا خللاً حقيقياً.
- ثم عطّل الحارس نفسه الدمج مرتين أخريين خلال يوم واحد من العمل عليه.

بوابة الجودة تعمل الآن (اختبارات · فحص نوعي صارم · بناء · ESLint بسقف · حارس طبقة البيانات). لكن **بوابة لا ينظر إليها أحد ليست بوابة** — ما دام الدمج ممكناً وهي حمراء، فهي تقرير يُتجاهَل لا مانع.

---

## الإعداد

`Settings → Branches → Add branch protection rule`، والنمط `main`:

| الإعداد | القيمة | السبب |
|---|---|---|
| **Require status checks to pass** | ✅ | الأساس. بدونه كل ما تحته بلا معنى |
| ↳ الفحص المطلوب | `checks` | اسم المهمة في `.github/workflows/quality.yml` |
| ↳ **Require branches to be up to date** | ✅ | يمنع «الدمج الصامت»: فرعان أخضران منفردين قد يكسران `main` معاً |
| **Require a pull request before merging** | ✅ | يمنع الدفع المباشر الذي يتخطّى الفحص |
| ↳ Required approvals | **0** | مستودع بمطوّر واحد؛ اشتراط موافقة يعطّل العمل بلا فائدة. ارفعها إلى 1 عند انضمام ثانٍ |
| **Do not allow bypassing** | ✅ | الاستثناء الإداري هو بالضبط ما جعل ثمانية أيام حمراء تمرّ |
| **Allow force pushes** | ❌ | تاريخ `main` لا يُعاد كتابته |
| **Allow deletions** | ❌ | — |
| **Require linear history** | اختياري | يجعل التاريخ أوضح؛ لا يمنع خطأً بذاته |
| Require signed commits | ❌ | يعطّل الدمج من واجهات Lovable وClaude Code بلا مقابل أمني هنا |

## وتنبيه على الفشل — مكمّل ضروري

الحماية تمنع دمج الأحمر، لكنها لا تُخبرك أنه أحمر. فعّل أحد الاثنين:

- **الأبسط:** `github.com/settings/notifications` ← فعّل **Actions → Failed workflows only**. يصل بريد عند كل فشل على `main`.
- **الأفضل لفريق:** خطوة `if: failure()` في `quality.yml` تُرسل إلى Slack أو بريد الفريق.

بدون أحدهما يبقى السيناريو الذي وقع فعلاً ممكناً: البوابة حمراء، ولا أحد يعلم.
